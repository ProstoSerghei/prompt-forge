# Prompt Forge

Однофайловая HTML-утилита для сборки структурированных промптов под задачи по коду.

## Что умеет

- Генерирует готовый промпт в реальном времени.
- Содержит основные секции для постановки задачи: цель, файлы контекста, требования, ограничения, стиль кода, критерии приемки и тесты.
- Поддерживает добавление кастомных файлов, ограничений, требований к стилю и правил формата ответа.
- Позволяет указать свое значение в селектах через вариант `Другое...`.
- Отмечает обязательные поля: цель, ожидаемый результат и функциональные требования.
- Имеет отдельный режим для ответа на уточняющие вопросы: вставка вопросов построчно, заполнение ответов, генерация готового текста.
- Работает без сборки и backend.

## Запуск

Откройте `index.html` в браузере.

Для Bootstrap и Bootstrap Icons используется CDN, поэтому для полной стилизации нужен доступ к интернету.

## Файлы

- `index.html` - вся утилита: HTML, CSS и JavaScript.
- `README.md` - описание проекта.
- `.gitignore` - исключения для локальных и временных файлов.
